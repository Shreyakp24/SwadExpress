# 🍔 SwadExpress

SwadExpress is a full-stack food ordering web application developed using Java, JSP, Servlets, JDBC, MySQL, HTML, CSS, and JavaScript. It allows users to browse restaurants, explore menus, add items to a cart, and place orders through a simple and responsive interface.

## 🚀 Features

- User Registration and Login
- Secure password encryption using BCrypt
- Browse available restaurants
- View restaurant menus
- Add and remove items from the shopping cart
- Place food orders
- User session management
- Responsive user interface

## ⚙️ Installation

### 1. Clone the repository

```bash
git clone https://github.com/Shreyakp24/SwadExpress.git
```

### 2. Open the project

Import the project into Eclipse IDE.

### 3. Configure Apache Tomcat

- Install Apache Tomcat 10
- Add Tomcat Server in Eclipse
- Deploy the project

### 4. Configure MySQL

Create a MySQL database and update the database connection details in your JDBC configuration.

### 5. Run the project

Start Tomcat and open:

```
http://localhost:8080/SwadExpress
```
